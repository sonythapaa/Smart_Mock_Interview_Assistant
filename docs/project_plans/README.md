# Project Plans

This folder contains the official planning documents for the Smart Mock Interview Assistant project.

## Documents

| Document | Purpose |
|---|---|
| `Project Specifications.pdf` | Defines the project topic, objectives, goals, and KPIs. |
| `Project Timeline.pdf` | Provides the project schedule, task dates, and deliverables. |
| `Data Management Plan.pdf` | Explains data collection, storage, documentation, security, and ethics. |
| `Pipeline Workflow.pdf` | Describes preprocessing, modelling, evaluation, and deployment plans. |
| `Test Plan.pdf` | Defines testing scope, quality checks, code review, and validation activities. |
| `Team Plan.pdf` | Defines team roles, communication, meetings, and working process. |
